# System Prompt

An [LLMHub](https://github.com/huangdihd/LLMHub) plugin that adds a system
prompt to requests passing through the gateway.

- **One prompt for every model**, set on the plugin's Configure page.
- **A prompt per model**, typed straight into that model's row on the Models
  page.
- Choose whether your prompt goes before the client's own system prompt, after
  it, or replaces it.

When both are set, the per-model prompt follows the global one.

## Install

Open **Plugins → Browse market** in LLMHub and install **System Prompt**, then
enable it.
